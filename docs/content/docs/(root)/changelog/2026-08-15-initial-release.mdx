---
title: "August 2026 - Initial Release"
date: 2026-08-15
---

We shipped the initial release of maccn with 19 macOS-inspired GPUI components for Rust and WebAssembly.

The library includes Badge, Box, Button, Checkbox, Glass Panel, Help Button, Label, Pop-Up Button, Progress, Radio Group, Search Field, Secure Field, Segmented Control, Separator, Slider, Spinner, Stepper, Switch, and Text Field.

Every control supports the five `NSControl.ControlSize` sizes, light and dark appearances, and a single system accent color.
