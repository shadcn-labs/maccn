**maccn** provides beautifully designed, accessible, and customizable macOS-inspired controls. Built on [GPUI](https://gpui.rs) and [gpui-base](https://github.com/longbridge/gpui-component), and designed to feel native on macOS.

## Philosophy

maccn follows the AppKit design language: every control carries the metrics, states, and keyboard behavior captured by [macvue](https://github.com/antonreshetov/macvue), re-expressed as composable Rust components.

Most macOS UI libraries are either too opinionated or too scattered. maccn is built for teams that want to ship quickly without giving up control:

- **Own Your Code:** Copy the components into your project and customize everything.
- **Start Fast:** Run one command and render your first UI with production-ready defaults.
- **Choose Your Engine:** Use the same components natively or compile to WebAssembly for the browser.

## Why maccn?
