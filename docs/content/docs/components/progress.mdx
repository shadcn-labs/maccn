## Definition

A horizontal progress bar that supports determinate (percentage) and indeterminate (busy) modes. The indeterminate mode sweeps a 40%-width accent bar across the track in a repeating animation.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacProgress, ProgressSize};

// Determinate progress
MacProgress::new("progress").value(68.0)

// Indeterminate (busy) mode
MacProgress::new("progress").indeterminate(true)

// Small size
MacProgress::new("progress")
    .size(ProgressSize::Small)
    .value(45.0)
```

### Sizes

| Size | Height |
| --- | --- |
| `Regular` | 10px |
| `Small` | 6px |

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `ProgressSize` | `Regular` |
| `value` | `f32` | `0.0` |
| `indeterminate` | `bool` | `false` |
