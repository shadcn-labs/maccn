## Definition

A horizontal slider with a draggable thumb, matching macOS `NSSlider` appearance. The thumb and track dimensions scale with `ControlSize`.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacSlider;
use gpui_base::slider::SliderState;

let slider = cx.new(|_| SliderState::new().min(0.).max(100.).default_value(64.));

MacSlider::new("slider", &slider)
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacSlider::new("slider-xl", &slider)
    .size(MacControlSize::ExtraLarge)
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `MacControlSize` | `Regular` |
| `disabled` | `bool` | `false` |

### State

The slider requires an `Entity<SliderState>` created via:

```rust
SliderState::new()
    .min(0.0)
    .max(100.0)
    .default_value(50.0)
```

| Method | Description |
| --- | --- |
| `min(value)` | Sets the minimum value. |
| `max(value)` | Sets the maximum value. |
| `default_value(value)` | Sets the initial value. |
