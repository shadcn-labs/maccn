## Definition

A translucent panel with macOS vibrancy effects. Two material options: `Regular` (70%/32% opacity for light/dark) and `Clear` (28%/12% opacity).

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacGlassPanel, GlassMaterial};

MacGlassPanel::new("panel")
    .material(GlassMaterial::Regular)
    .child("Content here")
```

### Clear Material

```rust
MacGlassPanel::new("clear-panel")
    .material(GlassMaterial::Clear)
    .child("Lighter blur")
```

## API

### Props

| Prop       | Type            | Default   |
| ---------- | --------------- | --------- |
| `material` | `GlassMaterial` | `Regular` |

### Materials

| Material  | Description                                          |
| --------- | ---------------------------------------------------- |
| `Regular` | 70% opacity (light) / 32% (dark). Standard vibrancy. |
| `Clear`   | 28% opacity (light) / 12% (dark). Lighter blur.      |

### Traits

| Trait           | Description                        |
| --------------- | ---------------------------------- |
| `Styled`        | Set background, border, etc.       |
| `ParentElement` | Add child elements via `.child()`. |
