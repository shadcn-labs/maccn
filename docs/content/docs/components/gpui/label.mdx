## Usage

```rust
use maccn::{MacLabel, LabelStyle};

MacLabel::new("title")
    .style(LabelStyle::Title1)
    .child("Hello World");
```

## API

### Props

| Prop        | Type         | Default |
| ----------- | ------------ | ------- |
| `style`     | `LabelStyle` | `Body`  |
| `secondary` | `bool`       | `false` |

### LabelStyle

| Variant       | Size  | Weight |
| ------------- | ----- | ------ |
| `LargeTitle`  | 26px  | Normal |
| `Title1`      | 22px  | Normal |
| `Title2`      | 17px  | Normal |
| `Title3`      | 15px  | Normal |
| `Headline`    | 13px  | Bold   |
| `Body`        | 13px  | Normal |
| `Callout`     | 12px  | Normal |
| `Subheadline` | 11px  | Normal |
| `Footnote`    | 10px  | Normal |
| `Caption1`    | 10px  | Normal |
| `Caption2`    | 10px  | Normal |

### Traits

| Trait           | Description                 |
| --------------- | --------------------------- |
| `Styled`        | Set color, alignment, etc.  |
| `ParentElement` | Add content via `.child()`. |
