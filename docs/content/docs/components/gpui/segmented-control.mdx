## Usage

```rust
use maccn::{MacSegment, MacSegmentedControl};

MacSegmentedControl::new("view-toggle")
    .child(MacSegment::new("list").selected(true).child("List"))
    .child(MacSegment::new("grid").child("Grid"))
    .child(MacSegment::new("columns").child("Columns"));
```

## API

### MacSegmentedControl Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### MacSegment Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `selected` | `bool`           | `false`   |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### Events

| Event      | Payload                                |
| ---------- | -------------------------------------- |
| `on_click` | `(&ClickEvent, &mut Window, &mut App)` |
