## Usage

```rust
use gpui::Axis;
use maccn::{MacRadio, MacRadioGroup, MacControlSize};

MacRadioGroup::new("options")
    .axis(Axis::Vertical)
    .gap(8.)
    .child(MacRadio::new("opt1").checked(true).child("Option 1"))
    .child(MacRadio::new("opt2").child("Option 2"))
    .child(MacRadio::new("opt3").child("Option 3"));
```

## API

### MacRadioGroup Props

| Prop   | Type             | Default    |
| ------ | ---------------- | ---------- |
| `size` | `MacControlSize` | `Regular`  |
| `axis` | `Axis`           | `Vertical` |
| `gap`  | `f32`            | `8.0`      |

### MacRadio Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `checked`  | `bool`           | `false`   |
| `disabled` | `bool`           | `false`   |

### Events

| Event       | Payload                                      |
| ----------- | -------------------------------------------- |
| `on_change` | `(bool, &ClickEvent, &mut Window, &mut App)` |
