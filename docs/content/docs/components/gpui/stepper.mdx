## Usage

```rust
use maccn::MacStepper;

MacStepper::new("quantity")
    .on_increment(|_, _| {
        println!("Incremented");
    })
    .on_decrement(|_, _| {
        println!("Decremented");
    });
```

## API

### Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### Events

| Event          | Payload                   |
| -------------- | ------------------------- |
| `on_increment` | `(&mut Window, &mut App)` |
| `on_decrement` | `(&mut Window, &mut App)` |
