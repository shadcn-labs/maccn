## Usage

```rust
use maccn::MacBadge;

MacBadge::new("count").child("12");
```

## API

### Constructor

| Method              | Description                                    |
| ------------------- | ---------------------------------------------- |
| `MacBadge::new(id)` | Creates a new badge with the given element ID. |

### Traits

| Trait           | Description                               |
| --------------- | ----------------------------------------- |
| `Styled`        | Set background, text color, padding, etc. |
| `ParentElement` | Add content via `.child()`.               |
