title: Secure Field

<ComponentPreview name="secure-field/Basic" />

## Import

```rust
use maccn::MacSecureField;
```

## Usage

```rust
let state = cx.new(|cx| {
    InputState::new(window, cx)
        .placeholder("Passphrase")
        .masked(true)
});

MacSecureField::new("password", &state);
```

## Sizes

<ComponentPreview name="secure-field/Sizes" />

```rust
use gpui::div;
use maccn::{MacControlSize, MacSecureField};

div()
    .flex()
    .items_center()
    .gap_2()
    .child(
        MacSecureField::new("secure-xl", &state)
            .size(MacControlSize::ExtraLarge)
            .w(px(220.)),
    )
    .child(
        MacSecureField::new("secure-s", &state)
            .size(MacControlSize::Small)
            .w(px(160.)),
    )
```

## Disabled

<ComponentPreview name="secure-field/Disabled" />

```rust
MacSecureField::new("secure-d", &state)
    .disabled(true)
    .w(px(220.))
```

## API

### Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### InputState

`MacSecureField::new(id, &state)` requires an `Entity<InputState>` created with `.masked(true)`.
