## Usage

```rust
use maccn::{MacButton, ButtonVariant, MacControlSize};

MacButton::new("save").child("Save");

MacButton::new("delete")
    .variant(ButtonVariant::Destructive)
    .child("Delete");
```

## API

### Props

| Prop       | Type             | Default    |
| ---------- | ---------------- | ---------- |
| `variant`  | `ButtonVariant`  | `Bordered` |
| `size`     | `MacControlSize` | `Regular`  |
| `disabled` | `bool`           | `false`    |

### Variants

| Variant       | Description                        |
| ------------- | ---------------------------------- |
| `Bordered`    | Neutral bordered button (default). |
| `Prominent`   | Accent-filled button.              |
| `Destructive` | Red bordered destructive button.   |

### Events

| Event      | Payload                                |
| ---------- | -------------------------------------- |
| `on_click` | `(&ClickEvent, &mut Window, &mut App)` |
