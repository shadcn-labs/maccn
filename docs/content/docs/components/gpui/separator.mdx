## Definition

A 1px dividing line in the theme's separator color. Supports horizontal and vertical orientations.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacSeparator, SeparatorAxis};

// Horizontal (default)
MacSeparator::new("sep-h")

// Vertical
MacSeparator::new("sep-v")
    .axis(SeparatorAxis::Vertical)
```

## API

### Props

| Prop   | Type            | Default      |
| ------ | --------------- | ------------ |
| `axis` | `SeparatorAxis` | `Horizontal` |
