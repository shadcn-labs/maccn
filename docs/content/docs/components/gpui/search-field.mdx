## Definition

A search input field with a magnifying glass icon and clear button. Wraps `MacTextField` in pill mode with search-specific styling.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacSearchField, InputState};

let state = cx.new_entity(InputState::new());

MacSearchField::new("search", state.clone())
    .on_submit(|value, _, _, cx| {
        println!("Search: {}", value);
    })
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacSearchField::new("xl", state.clone()).size(MacControlSize::ExtraLarge)
MacSearchField::new("l", state.clone()).size(MacControlSize::Large)
MacSearchField::new("r", state.clone()) // Regular (default)
MacSearchField::new("s", state.clone()).size(MacControlSize::Small)
MacSearchField::new("m", state.clone()).size(MacControlSize::Mini)
```

### Disabled

```rust
MacSearchField::new("sf", state.clone()).disabled(true)
```

## API

### Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### Methods

| Method                    | Description             |
| ------------------------- | ----------------------- |
| `state.clean(window, cx)` | Clears the field value. |

### Events

| Event       | Payload                                      |
| ----------- | -------------------------------------------- |
| `on_submit` | `(&str, &ClickEvent, &mut Window, &mut App)` |
