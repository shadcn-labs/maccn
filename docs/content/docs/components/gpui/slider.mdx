## Usage

```rust
use gpui::Context as _;
use gpui_base::slider::SliderState;
use maccn::MacSlider;

let state = cx.new(|_| SliderState::new().min(0.).max(100.).default_value(50.));

MacSlider::new("volume", &state);
```

## API

### Props

| Prop       | Type             | Default   |
| ---------- | ---------------- | --------- |
| `size`     | `MacControlSize` | `Regular` |
| `disabled` | `bool`           | `false`   |

### SliderState

`MacSlider::new(id, &state)` requires an `Entity<SliderState>`.

| Method                 | Description             |
| ---------------------- | ----------------------- |
| `min(f32)`             | Sets the minimum value. |
| `max(f32)`             | Sets the maximum value. |
| `default_value(f32)`   | Sets the initial value. |
