## Definition

A macOS sidebar count badge (`NSTableView` badge): a translucent neutral capsule with secondary text. One size only — AppKit badges carry no `ControlSize`. The kits ship no badge masters, so the metrics are modeled on the live macOS sidebar.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacBadge;

MacBadge::new("badge").child("New")
```
