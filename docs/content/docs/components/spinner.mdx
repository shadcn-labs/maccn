## Definition

An animated 8-blade spinner that rotates continuously in an 800ms repeating animation. Each blade has decreasing opacity.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacSpinner, SpinnerSize};

// Default spinner
MacSpinner::new("spinner")

// Small spinner
MacSpinner::new("spinner").size(SpinnerSize::Small)
```

### Sizes

| Size | Dimensions |
| --- | --- |
| `Regular` | 32px |
| `Small` | 16px |

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `SpinnerSize` | `Regular` |
| `color` | `Hsla` | `theme.spinner_color` |
