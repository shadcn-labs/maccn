## Definition

A stepper control with up and down chevron buttons, separated by a vertical line, matching macOS `NSStepper`.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacStepper;

MacStepper::new("stepper")
    .on_increment(|_, _| { /* increment */ })
    .on_decrement(|_, _| { /* decrement */ })
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacStepper::new("stepper-xl").size(MacControlSize::ExtraLarge)
MacStepper::new("stepper-l").size(MacControlSize::Large)
MacStepper::new("stepper-r") // Regular (default)
MacStepper::new("stepper-s").size(MacControlSize::Small)
MacStepper::new("stepper-m").size(MacControlSize::Mini)
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `MacControlSize` | `Regular` |
| `disabled` | `bool` | `false` |

### Events

| Event | Payload |
| --- | --- |
| `on_increment` | `(&mut Window, &mut App)` |
| `on_decrement` | `(&mut Window, &mut App)` |
