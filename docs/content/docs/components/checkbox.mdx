## Definition

A tri-state checkbox supporting checked, unchecked, and indeterminate states, with macOS-native styling. The checkbox box size, radius, and mark size scale with `ControlSize`.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacCheckbox, MacCheckboxState};

// Simple checked checkbox
MacCheckbox::new("check")
    .checked(true)
    .child("Enable updates")

// With change handler
MacCheckbox::new("check")
    .on_change(|state, _, _, cx| {
        println!("State: {:?}", state);
    })
    .child("Toggle")
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacCheckbox::new("check-xl")
    .size(MacControlSize::ExtraLarge)
    .checked(true)
    .child("XL")
MacCheckbox::new("check-l")
    .size(MacControlSize::Large)
    .checked(true)
    .child("L")
MacCheckbox::new("check-r").checked(true).child("R")
MacCheckbox::new("check-s")
    .size(MacControlSize::Small)
    .checked(true)
    .child("S")
MacCheckbox::new("check-m")
    .size(MacControlSize::Mini)
    .checked(true)
    .child("M")
```

### States

| State | Description |
| --- | --- |
| `Checked` | Check mark is shown. |
| `Unchecked` | Empty state. |
| `Indeterminate` | Dash mark is shown. |

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `MacControlSize` | `Regular` |
| `checked` | `bool` | `false` |
| `indeterminate` | `bool` | `false` |
| `disabled` | `bool` | `false` |

### Events

| Event | Payload |
| --- | --- |
| `on_change` | `(CheckboxState, &ClickEvent, &mut Window, &mut App)` |
