## Definition

A circular button with a "?" glyph, used for contextual help in macOS interfaces. The glyph size scales with `ControlSize`.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacHelpButton;

MacHelpButton::new("help")
    .on_click(|_, _, cx| {
        println!("Help clicked");
    })
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacHelpButton::new("help-xl").size(MacControlSize::ExtraLarge)
MacHelpButton::new("help-l").size(MacControlSize::Large)
MacHelpButton::new("help-r") // Regular (default)
MacHelpButton::new("help-s").size(MacControlSize::Small)
MacHelpButton::new("help-m").size(MacControlSize::Mini)
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `MacControlSize` | `Regular` |
| `disabled` | `bool` | `false` |

### Events

| Event | Payload |
| --- | --- |
| `on_click` | `(&ClickEvent, &mut Window, &mut App)` |
