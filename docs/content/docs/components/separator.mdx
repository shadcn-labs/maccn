## Definition

A 1px dividing line in the theme's separator color, supporting horizontal and vertical orientations.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacSeparator;
use gpui::Axis;

// Horizontal (default)
MacSeparator::new("sep")

// Vertical
MacSeparator::new("sep").axis(Axis::Vertical)
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `axis` | `Axis` | `Horizontal` |
