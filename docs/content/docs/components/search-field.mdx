## Definition

A search input field with a leading magnifier icon and an automatic clear (X) button when content is present. Internally wraps `MacTextField` in pill mode.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::MacSearchField;
use gpui_base::input::InputState;

let state = cx.new(|cx| InputState::new(window, cx).placeholder("Search"));

MacSearchField::new("search", &state)
```

### Sizes

All five macOS control sizes; `regular` is the default.

```rust
MacSearchField::new("search-xl", &state)
    .size(MacControlSize::ExtraLarge)
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `MacControlSize` | `Regular` |
| `disabled` | `bool` | `false` |

### State

The search field requires an `Entity<InputState>` created via:

```rust
InputState::new(window, cx).placeholder("Search")
```

| Method | Description |
| --- | --- |
| `state.clean(window, cx)` | Clears the input (called automatically by the X button). |
