## Definition

A translucent container that applies macOS vibrancy and blur effects. Supports `Regular` and `Clear` materials. The background and rim colors adapt automatically to light and dark appearances.

## Installation

```toml
[dependencies]
maccn = "0.1"
```

## Usage

```rust
use maccn::{MacGlassPanel, GlassMaterial};

// Default translucent material
MacGlassPanel::new("panel")
    .child(MacLabel::new("title").child("Content"))

// Clear material with less opacity
MacGlassPanel::new("panel")
    .material(GlassMaterial::Clear)
    .child(MacLabel::new("title").child("Content"))
```

### Materials

| Material | Light Background | Dark Background |
| --- | --- | --- |
| `Regular` | `rgba(255,255,255,0.7)` | `rgba(0,0,0,0.32)` |
| `Clear` | `rgba(255,255,255,0.28)` | `rgba(0,0,0,0.12)` |

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `material` | `GlassMaterial` | `Regular` |
