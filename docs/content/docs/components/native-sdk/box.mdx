## Definition

A grouped settings container (`NSBox`): a rounded rectangle that visually groups related controls. Provides a labeled region with padding and a subtle border.

## Markup

```xml
<box width="300" padding="16">
  <column gap="8">
    <text>Settings</text>
    <text foreground="text_muted">Grouped controls</text>
  </column>
</box>
```

## Programmatic construction (Zig)

```zig
ui.panel(.{ .width = 300, .padding = 16, .variant = .boxed }, .{
    ui.column(.{ .gap = 8 }, .{
        ui.text(.{}, "Settings"),
        ui.text(.{ .style_tokens = .{ .foreground = .text_muted } }, "Grouped controls"),
    }),
})
```

## Attributes

| Attribute | Description                     |
| --------- | ------------------------------- |
| `width`   | Definite width (plain number).  |
| `height`  | Definite height (plain number). |
| `padding` | Uniform padding (plain number). |
