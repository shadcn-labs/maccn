## Definition

A text label with macOS typography styles. Supports 11 built-in text styles matching AppKit's text label hierarchy.

## Markup

```xml
<column gap="4">
  <label style="large_title">Large Title</label>
  <label style="title1">Title 1</label>
  <label style="title2">Title 2</label>
  <label style="title3">Title 3</label>
  <label style="headline">Headline</label>
  <label style="body">Body</label>
  <label style="callout">Callout</label>
  <label style="subheadline">Subheadline</label>
  <label style="footnote">Footnote</label>
  <label style="caption1">Caption 1</label>
  <label style="caption2">Caption 2</label>
  <label style="body" secondary="true">Secondary text</label>
</column>
```

## Programmatic construction (Zig)

```zig
ui.column(.{ .gap = 4 }, .{
    ui.text(.{ .style = .large_title }, "Large Title"),
    ui.text(.{ .style = .title1 }, "Title 1"),
    ui.text(.{ .style = .body }, "Body"),
    ui.text(.{ .style = .body, .secondary = true }, "Secondary text"),
})
```

## Attributes

| Attribute   | Description                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`      | Text value; a literal or one `{binding}`.                                                                                                                            |
| `style`     | Typography style: `large_title` \| `title1` \| `title2` \| `title3` \| `headline` \| `body` \| `callout` \| `subheadline` \| `footnote` \| `caption1` \| `caption2`. |
| `secondary` | Muted text color; `true`/`false`.                                                                                                                                    |
